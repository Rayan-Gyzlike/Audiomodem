# Аудиомодем

Передача данных через звук: Python/DSP-бекенд (FastAPI + WebSocket)
и веб-фронтенд с живой спектрограммой-водопадом, чат-интерфейсом,
поддержкой передачи файлов и ARQ-протоколом подтверждения приёма.

---

## 1. Рабочее решение

Аудиомодем передаёт текст и файлы через акустический канал
(динамик → воздух → микрофон) используя:

- **FSK-модуляция** (1200/2200 Гц, 100 бит/сек) с непрерывной фазой
- **Reed-Solomon** (10 байт избыточности) — коррекция до 5 повреждённых байт
- **CRC32** — контроль целостности данных
- **ARQ-протокол** — автоматический повтор при ошибке (ACK/NACK через Web Audio API)
- **Manual ACK** — кнопка ручного подтверждения приёма в GUI
- **Спектрограмма-водопад** — визуализация аудиосигнала в реальном времени
- **Файловая фрагментация** — автоматическое разбиение файлов на чанки по 128 байт

## 3. Инструкции по запуску

### Запуск из исходников (одна команда)

```powershell
powershell -ExecutionPolicy Bypass -File start.ps1
```

Откроется браузер на `http://127.0.0.1:8000/`.

### Запуск вручную

```powershell
cd src
..\..venv\Scripts\python.exe run.py
```

### Запуск через .exe

```powershell
.\artifacts\audio-modem.exe
```

### Установка зависимостей

```powershell
python -m venv .venv
.\.venv\Scripts\pip.exe install -r src\requirements.txt
```

## 4. Описание архитектуры и протокола

### Формат кадра данных

```
[ Преамбула 32 бита (чередование 0/1) ]
[ Синхрослово 16 бит (0x2DD4) ]
[ Длина 8 бит (размер RS-кода) ]
[ Данные (LEN байт, включая RS + CRC32) ]
```

Внутри кадра: `UTF-8 → CRC32 (4 байта) → Reed-Solomon (10 байт)`

### Контрольные кадры (ACK/NACK)

```
[ Преамбула 8 бит ] [ Синхрослово 16 бит ] [ Команда 8 бит: 0x06=ACK, 0x15=NACK ]
```

Короткая преамбула — контрольные кадры передаются за ~0.32 сек.

### ARQ-протокол

1. Передатчик отправляет кадр и ждёт ACK/NACK 5.0 сек
2. Приёмник декодирует, проверяет CRC32
3. CRC32 ОК → ACK через Web Audio API в браузере (100мс задержка для сброса TX)
4. CRC32 ОШИБКА → NACK (запрос повтора)
5. Таймаут/NACK → повтор (до 3 раз, backoff 100-500мс)

### Self-muting

После передачи микрофон блокируется на `duration + 0.6 сек`
для защиты от собственного эха.

### Спектрограмма-водопад

Живая визуализация частотного спектра микрофона через Canvas API.
Цветовая карта: синий (тихо) → зелёный → жёлтый → красный (громко).

## 5. Ограничения решения

| Параметр | Значение |
|---|---|
| Скорость передачи | **100 бит/сек** (~12.5 байт/сек) |
| Макс. размер кадра | **255 байт** (с RS-избыточностью) |
| Макс. текст за кадр | **~245 символов** UTF-8 |
| Таймаут ACK | **5.0 сек** (MAX_RETRIES=3) |
| Файлы | Фрагментация на чанки по **128 байт** |
| Эхо | Self-mute **0.6 сек** после передачи |
| Мультиплеер | До **4 пар** устройств (частотные каналы) |
